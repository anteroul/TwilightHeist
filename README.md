# Twilight Heist

An example project for [Messier Engine](https://github.com/anteroul/messier-engine), a WebGPU game engine and editor
that runs in the browser. It's a small stealth game that shows off shadows and transparency.

A thief sneaks around a walled castle garden at dusk, takes the six coins hidden in it and slips out through the gate.
Lamps on three watchtowers sweep the lawns, and whatever their light reaches, they see: in the shadow of a hedge, a
statue or a wall you're hidden. Stay in a beam too long and the alarm sends you back to the start.

| What | Where |
| --- | --- |
| **Cascaded shadows** | The low sun throws long shadows across the whole garden, sharp up close and still there at the far wall |
| **Spot light shadows** | The watchtower lamps, and the candlelight shining out of the chapel door; the game's detection follows them exactly |
| **Point light shadows** | The brazier in the middle of the garden casts shadows outward in every direction |
| **Alpha blending** | The chapel's stained-glass windows and the pond |
| **Additive blending** | The brazier's flame, the lamps' halos and the fireflies |

In Play: `WASD` / arrows sneak, `R` restarts.

## Open it

You need the Messier editor in Chrome or Edge (project folders use the File System Access API).

1. Clone this repository.
2. In the editor, **☰ → Open Project…** and pick the cloned folder.
3. Press **▶ Play**, or **Build** to download it as a single web page.

## Where it comes from

The scene is generated by the engine repository's `src/twilightHeist/` with `npm run generate:heist`; everything in it
is built from primitives. Regenerating replaces the project files (it keeps `.git`, this README and `LICENSE`), so
changes made in the editor are overwritten the next time it's regenerated.
